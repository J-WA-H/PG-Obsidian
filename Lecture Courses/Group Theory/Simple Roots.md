Previously, we have ignored the positivity of [[Roots and Weights]], but this must be introduced to further understand weights.

In some arbitrary basis for the Cartan subalgebra, the components $\mu_{1},\mu_{2},\dots,$ of the weight are fixed. A weight is positive if its first non-zero component is positive and the weight is negative if its first non-zero component is negative. While this is basis dependent, it does have the properties we want.

For example, in $SU(3)$, the $\mathbf{3}$-representation looks like
![[Pasted image 20261026155639.png|293]]

The weight $(0,-1/\sqrt{ 3 })$ is negative because its first component is zero so the sign is determined by the sign of the second component. With this definition, we can define an ordering as
$$\mu>\nu \text{ if } \mu-\nu \text{ is positive}.\tag{5.1}$$
This allows us to talk about the highest weight in a representation. In the adjoint representation, the positive roots correspond to raising operators and the negative roots to lowering operators. The highest weight of any representation has the property that we cannot raise it, so that all generators corresponding to positive roots must annihilate the corresponding state. In the $SU(3)$ adjoint representation, in our usual basis, the positive roots are on the right and the negative on the left
![[Pasted image 20261026160117.png|283]]

It can be seen that some of the positive roots can be built from others, so it makes sense to define simple roots as positive roots that cannot be written as a sum of the positive roots. If a weight is annihilated by by the generators of all simple roots, it is the highest weigh of an irreducible representation. From the geometry of simple roots, it is possible to reconstruct the entire algebra:

1. If $\alpha$ and $\beta$ are different simple roots, then $\alpha-\beta$ is not a root. This is true because one of them, say $\beta$, is larger, so that $\beta-\alpha$ is positive, but then $\beta$ is the sum of two roots, $\beta$ and $\beta-\alpha$.
2. Because $\alpha-\beta$ isn't a root
	$$E_{-\alpha}\ket{E_{\beta}} =E_{-\beta}\ket{E_{\alpha}} =0\tag{5.2}.$$
	Then using
	$$\frac{{\alpha \cdot \beta}}{\alpha^2}=-\frac{1}{2}(p-q)\tag{5.3},$$
	the integer $q$ is zero. Similarly in
	$$\frac{{\beta \cdot\alpha}}{\beta^2}=-\frac{1}{2}(p'-q')\tag{5.4},$$
	the integer $q'$ is zero. Thus
	$$\frac{{\alpha \cdot \beta}}{\alpha^{2}} = -\frac{p}{2},\qquad \frac{{\beta \cdot\alpha}}{\beta^2}=-\frac{p'}{2}.\tag{5.5}$$
	Knowing the integers $p,p'$ for each simple root is equivalent to knowing the angles between the simple roots, and their relative lengths because
	$$\cos \theta_{\alpha\beta} = -\frac{\sqrt{ pp' }}{2},\qquad \frac{\beta^2}{\alpha^2}=\frac{p}{p'}\tag{5.6}.$$
3. The angle between the first roots satisfies $\frac{\pi}{2}\leq \theta<\pi$.
4. Any positive root $\phi$ can be written as a linear combination of simple roots with non-negative integer coefficients $k_{\alpha}$,
$$\phi=\sum_{\alpha}k_{\alpha}\alpha \tag{5.7}.$$
5. The simple roots are not only linearly independent, they are complete so the number of simple roots is equal to $m$, the rank of the algebra, the number of Carton generators.

The entire algebra can be constructed from simple roots. First consider
$$\frac{{\alpha \cdot \mu}}{\alpha^{2}}+p=j, \qquad \frac{{\alpha \cdot \mu}}{\alpha^2}-q=-j.\tag{5.8}$$
This follows because a state $\mu$ with weight $\mu$ in any irreducible representation must have some component that transforms under the largest spin representation of the $SU(2)$ algebra associated with $\alpha$, generated by
$$E^{\pm}\equiv |\alpha|^{-1}E_{\pm\alpha}, \qquad E_{3}\equiv |\alpha|^{-2}\alpha \cdot H\tag{5.9}.$$
The largest spin is $j$. In general $\ket{\mu}$ may also have lower spin components, but $j$ is the highest one. It must be there so that $(E^+)^p\ket{\mu}$ transforms like a $\ket{j,j}$ state, which is non-zero, but annihilated by another $E^{+}$, and $(E^{-})^{m}\ket{\mu}$ transforms like a $\ket{j,-j}$ state, annihilated by another $E^{-}$. Adding these two relations gives the master equation, but subtracting them gives $p+q=2j$. Thus, if we know $p,q$, we know the highest spin representation that overlaps with the weight state.

If $\mu$ is a root in the adjoint representation, that simplifies things. As each root appears only one n the adjoint representation, if we know $p,q$ and therefore $j$ for a root $\beta$, we can conclude that $\ket{\beta}$ is the state with $E_{3}=\alpha \cdot \beta/\alpha^2$ in the spin-$j$ representation,
$$\ket{\beta} =\ket{j,\alpha \cdot \beta/\alpha^2}\tag{5.10}. $$
It is completely determined up to a phase. Thus we know exactly where $E^{\pm}$ acts, up to phases.

Example: $G_{2}$
Suppose an algebra has simple roots 
$$\alpha^{1}=(0,1), \qquad \alpha^{2}=(\sqrt{ 3 }/2,-3/2)\tag{5.11}.$$
This is an allowed pairing as:
$$(\alpha^{1})^{2}=1,\quad (\alpha^{2})^{2}=3, \quad \alpha^{1}\cdot\alpha^{2}=-\frac{3}{2}, \quad \frac{{2\alpha^{1}\cdot \alpha^{2}}}{(\alpha^{1})^{2}} = -3=-p, \quad \frac{{2\alpha^{1}\cdot \alpha^{2}}}{(\alpha^{2})^{2}}=-1=-p'\tag{5.12}.$$
The angle between the roots is determined by
$$\cos \theta_{\alpha^{1}\alpha^{2}}= -\frac{\sqrt{ pp' }}{2}= -\frac{\sqrt{ 3 }}{2}\implies \theta_{\alpha^{1}\alpha^{2}}=150^{\circ}\tag{5.13}.$$
