In Herwig, the generation of hard processes is automated, using an external library to calculate the scattering amplitudes, while other methods needed to assemble full NLO QCD matched and/or merged cross-sections are provided within the program itself. The module responsible, matchbox, contains modules for bookkeeping, diagram generation and mapping, the creation of subtraction terms, phase space sampling, scale choices, generation cuts, and parton shower matching to both available shower modules.

Once a process has been requested, Matchbox determines the possible contributing partonic subprocesses based on conservation rules (That can be lifted for BSM), scans the repositry for amplitude objects which claim to be capable of calculating the desired process either at tree level, loop level, or both, and will then determine the Feynman diagram topologies.

Since each amplitude can represent more than one process through the use of crossing, amplitudes are hooked into the actual matrix element objects which represent a contribution to the total cross-section. If a matching to a parton shower is requested, Matchbox will also supplement the subtraction terms by the matching subtractions and rearrange the virtual, integrated, and real subtracted contributions.
